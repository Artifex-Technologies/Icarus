# References

Projects I shared or found are references for Icarus: they show what a vehicle tool can do and how a device or format works,
so the gaps in Icarus can be filled. Nothing is copied from them, not code and not data: Icarus's code is written for Icarus,
from the standards and from what each reference teaches. This page credits what was learned from where.

One exception, my decision of 2026-11-27: OBDex's trouble-code texts are bundled as data (below), because they are a
public-domain dedication (CC0) and give every standard code its depth offline.

| Icarus | Learned from | What |
| --- | --- | --- |
| The Tactrix OpenPort 2.0 driver (`crates/icarus-obd/src/openport.rs`) | NikolaKozina's and Dale Schultz's j2534 library for Linux and macOS, https://github.com/NikolaKozina/j2534 (BSD 3-Clause) | the cable's command words, their answers and the layout of the packets it sends |
| The Drewtech Mongoose Pro driver (`crates/icarus-obd/src/mongoose.rs`) | roffe/gocan's native Mongoose Pro GM II driver, https://github.com/roffe/gocan (MIT) | the wire protocol: the packet layout and its check word, the commands of the open, connect, filter and send, the status codes |
| The bench wiring drawings for the 2016-2017 Tacoma 3.5 L automatic ECM (`Schematics/Toyota Tacoma 2016-2023`) | TacomaWorld members' excerpts of Toyota's factory wiring diagrams and owners' posts there (a 2017 Tacoma's CAN pins, two bench revivals), https://www.tacomaworld.com (each post is linked in that folder's README); PCMflash's manual, v1.08, https://pcmflash.ru/downloads/pcmflash_46.pdf?108; Toyota's technical service bulletins on NHTSA (T-SB-0077-16, T-SB-0062-18, T-SB-0043-20, T-SB-0092-20, T-SB-0134-16), https://static.nhtsa.gov/odi/tsbs/; the J1962 socket from Wikipedia's On-board diagnostics article and obdtester.com | which ECM pins carry +B, +B2, IGSW and the grounds, and their wire colors; the connector names, pin counts and housings; the minimal bench layout (PCMflash's drawing, whose power and ground pins match the factory diagram); the likely CAN pair (PCMflash and a 2017 Tacoma owner's TacomaWorld post) and the likely BOOT pin (PCMflash only), which no factory excerpt shows, so both stay to be checked in TIS; which part numbers make up the 2016-2017 automatic family, and the voltage window for flashing |
| Trouble codes in depth (`crates/icarus-obd/src/obdex.rs`, data in `crates/icarus-obd/data/obdex`) | OBDex, https://github.com/foerbsnavi/OBDex (data CC0 1.0), its `generic.min.json` at commit 9ba1ffa | bundled, the one exception: the 9,533 generic SAE J2012 codes' texts (what is checked, causes, symptoms, flags, the repair, sources), English, made by `examples/obdex_import` |
| The sweep gate for chassis and driver-assist modules (`moddata::Gates::sweep`, used by `obd asbuilt`) | navyansh1/CAR-OBD-Dashboard-AI on GitHub | the idea only: a sweep of identifiers keeps off chassis modules unless they are listed (its report of a sweep setting a chassis code on a Kia is a lead, not a fact) |
| The sweep that hears each module's own answer ID (`uds::ScanGuard`, `Link::probe`) | CalmAussie/obd2-reader and Aleksei327/ESP32-C5-OBD2-Scanner on GitHub | the idea only: listen for a module's answer on any diagnostic ID, not only at its request ID + 8; Icarus's sweep also never sends on an answer ID it has heard |
| The VIN that `icarus mcp`'s `vehicle_check` gives a model, its last 6 characters hidden unless asked (`vin::masked`) | CalmAussie/obd2-reader, an Android ELM327 app, https://github.com/CalmAussie/obd2-reader (MIT); speed785/open-mechanic, an OBD-II tool that hands live data and codes to Claude, https://github.com/speed785/open-mechanic (MIT) | hiding only the VIN's last six characters (obd2-reader's Hide VIN setting); that what an OBD tool tells a model may go on to the cloud, so it should hold no more than an explanation needs (open-mechanic) |
| The airbag list's Nissan and Honda entries (`actuator::SRS_CAN`, and the `honda` profile; ICA-108) | the Nissan Leaf CAN bus messages README, https://github.com/dalathegreat/leaf_can_bus_messages (GPL-3.0), its "What about active CAN-polling?" table; Caldis's Honda Civic Type R (FL5) diagnostic reference, https://github.com/Caldis/fl5-can-signals (documentation CC BY-SA 4.0), its module table | facts only, no data taken: the Leaf's airbag unit asked on 752 and answering on 772; module address 53 is the FL5's SRS unit, so 18DA53F1 and 18DAF153 under ISO 15765-4's fixed addressing. The leads for both came from CalmAussie/obd2-reader, which is not counted as a source; its GM (247) and Stellantis (744/4C4) leads have no independent source yet and stay out |
| Modules' serial numbers masked in captures (`capture::mask_serials`) | pyudskit's table of ISO 14229-1 data identifiers, https://pyudskit.readthedocs.io/en/latest/reference/did-table/; BMW's KWP2000 job descriptions (SGBD documentation), https://emdzej.github.io/ediabasx-docs-sgbd/ | F18C is the ECU serial number in UDS; BMW's KWP2000 modules give the supplier's serial number on `1A 89` (SERIENNUMMER_LESEN) |
